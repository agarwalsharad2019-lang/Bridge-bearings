# Railway Bridge Bearings — Papermorph Showcase

This is a runnable static showcase prototype for:

**Railway Bridge Bearings: Functions, Types and Selection**

Open `site/railway-bridge-bearings/index.html` in a browser. It uses no paid APIs, no external images, and no backend. The prototype includes:

- bearing-function overview;
- fixed, guided, and free bearing cards;
- animated expansion, contraction, rotation, and longitudinal movement;
- stepwise load-transfer diagram;
- steel/RCC/PSC selection placeholders;
- user-supplied numerical explorer for `ΔL = α × L × ΔT`;
- draft knowledge check;
- visible source and engineering-evidence boundaries.

The source register is intentionally empty. Replace `TBD` entries only with approved documents and reviewed numerical data before using the module for engineering training.
